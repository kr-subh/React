# React Projects & Practice Repository

Collection of React applications, exercises, and practice projects.

## Projects Overview

| Directory | Description |
| :--- | :--- |
| **[API](./API)** | React application exploring API consumption, data fetching, and handling asynchronous requests. |
| **[Card](./Card)** | UI card component implementations and design patterns. |
| **[Practice](./Practice)** | Core React concepts and hands-on practice modules. |
| **[React_route](./React_route)** | Routing and page navigation with React Router. |
| **[Test](./Test)** | Testing and component experimentation. |
| **[Test1](./Test1)** | Additional component testing and features. |
| **[UseEffect](./UseEffect)** | Hands-on examples exploring React's `useEffect` hook and side-effects. |
| **[practice2](./practice2)** | Advanced React exercises and state management practice. |

## Getting Started

Each project is a standalone Vite + React application. To run any project:

```bash
cd <project-folder-name>
npm install
npm run dev
```
